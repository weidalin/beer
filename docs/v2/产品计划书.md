## 四、功能详细规格

### F-201 七牛云 CDN 图片上传

**问题：** v1 图片存 Supabase Storage，速度受限；`.env` 里残留七牛云 AK/SK 明文（BUG-004）。

**v2 方案：** 所有图片上传统一走七牛云；AK/SK 从前端彻底移除，只存于 Supabase Edge Function。

**统一上传流程（所有场景复用）：**

```
用户 / 管理员在小程序内选图
  ↓
前端向 Supabase Edge Function 请求 UpToken
（AK/SK 仅存服务端，前端不可见）
  ↓
前端用 UpToken 直传七牛云
  ↓
上传成功 → 获取七牛 CDN 外链
  ↓
外链自动写入 Supabase 对应字段：
  · 故障照片  → repair_orders.photos[]
  · 产品主图  → products.images[0]
  · 产品详情图 → products.images[1..4]
```

**影响文件：**
- `useUpload.ts` — 重写，调签名接口 + 七牛直传，移除 Supabase Storage 依赖
- `ImageUploader` 组件 — 接口不变，仍返回 URL 字符串
- `.env` — 删除七牛 AK/SK；新增 `VITE_UPLOAD_SIGN_URL`（Edge Function 地址）

**验收标准（AC）：**
- ✅ 报修页上传3张故障照片，工单详情可正常预览，链接为七牛 CDN 域名
- ✅ 管理员在产品管理页上传主图，前台立即展示，链接为七牛 CDN 域名
- ✅ `.env` 不含七牛 SecretKey，BUG-004 关闭
- ✅ v1 历史 Supabase Storage 图片仍可正常展示（旧数据不迁移）
- ✅ 上传失败时提示"图片上传失败，请重试"，表单内容不丢失

### F-202 轻量登录模型

**问题：** v1 进入小程序即强制登录，体验重。

**v2 方案：** C 端浏览全程无需登录；触发需要身份的操作时，弹出底部半屏登录引导。管理员通过同一套微信登录识别身份。

**各场景登录要求：**

| 场景 | 是否需要登录 |
|------|------------|
| 浏览首页、产品列表/详情、合作方案、FAQ | ❌ 无需 |
| 全局搜索、查看配送区域 | ❌ 无需 |
| 提交合作意向信息（预约） | ❌ 无需登录，匿名提交即可 |
| 提交报修工单 | ✅ 提交时触发 |
| 查看"我的工单" | ✅ 进入时触发 |
| 在线客服 | ✅ 微信客服组件自带 |
| 运营管理（所有后台功能） | ✅ 需登录且 role = 'admin' |

**管理员身份判断：**

```
用户完成微信登录 → 获取 openid
  ↓
查询 Supabase users 表
  ↓
role = 'admin'  → "我的"页面显示"运营管理"入口
role ≠ 'admin'  → 隐藏"运营管理"入口（路由直接访问也会被拦截并返回首页）
```

**登录引导交互规范：**

| 时机 | 交互 |
|------|------|
| 触发需登录操作 | 底部弹出半屏浮层，标题"登录后继续"，微信一键登录按钮 |
| 登录成功 | 关闭浮层，自动继续原操作 |
| 用户点取消 | 关闭浮层，留在原页，不强制 |

**验收标准（AC）：**
- ✅ 未登录用户可完整浏览产品/方案，无任何拦截
- ✅ 未登录用户可直接填写并提交合作意向信息，无需登录
- ✅ 未登录点击"提交报修"→ 弹出登录引导；登录后自动继续提交
- ✅ 用户取消登录 → 浮层关闭，表单内容不丢失
- ✅ admin openid 登录后，"我的"页面出现"运营管理"入口；普通用户不可见
- ✅ 非 admin 直接访问 `/pages/admin/**` 路由 → 被拦截，提示"无权限"并返回首页

### F-203 全局关键词搜索

**搜索范围：**

| 数据源 | 搜索字段 |
|--------|---------|
| 产品（products） | 名称、规格、描述、标签 |
| 常见问题（faq） | 问题标题、答案内容 |

**交互设计：**
- 搜索框位于产品列表页顶部（固定，不随滚动消失）
- 首页顶部提供搜索快捷入口（点击跳转产品列表页并自动聚焦搜索框）
- 输入停止 **300ms** 后防抖触发，或点击"搜索"立即触发
- 结果分区：「产品」区块在上，「常见问题」区块在下
- 关键词在结果中**加粗高亮**
- 搜索框清空 → 恢复默认产品列表
- 无结果 → 空状态图 + "暂无相关内容" + "联系客服咨询"链接

**验收标准（AC）：**
- ✅ 搜索"打酒机"返回相关产品，关键词高亮
- ✅ 搜索"维修"返回相关 FAQ 条目
- ✅ 无结果时展示空状态，不空白，有客服入口
- ✅ 快速连续输入不会多次并发请求（防抖有效）
- ✅ 搜索框清空后产品列表恢复正常

```
小程序 ──► Supabase Storage ──► Supabase CDN URL ──► Supabase DB
```

## 八、交互规范

### 通用规范

| 规范项 | 要求 |
|--------|------|
| 空状态 | 所有列表无数据时展示图标+引导文案，禁止空白页 |
| 加载状态 | 网络请求期间展示骨架屏，禁止无反馈白屏 |
| 错误处理 | 网络失败显示"加载失败，点击重试"，禁止崩溃 |
| 表单校验 | 必填项提交前校验，错误红字展示在字段下方 |
| 操作反馈 | 提交/保存成功显示 Toast（持续2秒） |
| 危险操作 | 下架/删除前展示确认弹窗 |
| 点击区域 | 所有可交互元素最小高度 88rpx |

### 搜索规范

| 规范项 | 要求 |
|--------|------|
| 防抖延迟 | 输入停止 300ms 触发 |
| 高亮样式 | 匹配词加粗，颜色与主色一致 |
| 结果顺序 | 产品区块在上，FAQ 区块在下 |
| 清空行为 | 恢复默认产品列表 |

### 登录引导规范

| 时机 | 交互 |
|------|------|
| 触发需登录操作 | 底部弹出半屏浮层，标题"登录后继续"，微信一键登录 |
| 登录成功 | 关闭浮层，自动继续原操作 |
| 用户点取消 | 关闭浮层，停留原页，不强制 |
