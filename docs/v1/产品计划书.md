## 一、项目背景与目标

### 1.1 业务背景

本项目为**广东精酿啤酒一站式供应链**打造专属微信小程序，核心客户群体为：

- 宵夜档／夜市地摊
- 大排档／路边摊
- 小型餐饮档口

主营业务包括：

| 业务类型 | 说明 |
|---------|------|
| 桶装鲜啤配送 | 按需定期送货上门（珠三角当日达，其他地区走物流） |
| 打酒机设备维护 | 设备安装、保养、故障维修 |
| 设备提供 | 打酒机、啤酒车；支持**出售**或**租赁**两种方式，客户按需选择 |

### 1.2 为什么选择微信小程序

| 对比维度 | 网页版 | 微信小程序 |
|---------|--------|-----------|
| 触达方式 | 需要用户主动搜索/记住网址 | 微信内扫码、搜索、好友分享即可打开 |
| 用户登录 | 需注册账号 | 微信一键授权，无需注册 |
| 分享获客 | 分享链接体验差 | 分享卡片，好友点击直接进入 |
| 消息触达 | 无法主动推送 | 订阅消息（如维修进度、新预约提醒等） |
| 目标用户适配 | 需记住网址，门槛略高 | 档口老板日常用微信，使用习惯完全匹配 |
| 支付能力 | 需额外接入 | 本期**不接入**在线支付；价格面议，线下/转账结算 |
| 地理位置 | 需用户授权 | 微信授权后精准获取，用于配送定位 |

> **核心结论**：目标客户（宵夜档/大排档老板）的主要数字工具就是微信，小程序比网页更贴近他们的使用场景，获客成本更低，转化率更高。

### 1.3 建设目标

1. **品牌曝光**：微信生态内裂变传播，让更多档口主动找到我们
2. **线上获客**：原生表单提交客户意向，数据自动入库
3. **方案展示**：清晰呈现合作套餐，降低客户决策门槛
4. **客户服务**：在线报修、工单进度查询；M2–M3 以站内与 Toast 为准，**M4** 起接入订阅消息推送（见 §1.4、§5.2）
5. **产品自管理**：供应商通过小程序后台随时上下架产品，无需技术人员介入

### 1.4 一期范围与验收边界（与 MoSCoW 对齐）

| 主题 | 一期（M2–M3 必验收） | M4（Should） | 二期 / Could（不纳入一期验收） |
|------|---------------------|----------------|--------------------------------|
| **B 端看板** | 后台首页**轻量看板**：展示「今日新增客户数」「待处理工单数」及快捷入口、最新预约摘要 | 同左，数据随列表实时统计即可 | **数据报表**（多维分析、导出等） |
| **客户跟进** | 客户列表 + **客户详情**：可改 `status`（待跟进/已联系/已签约/已流失）、可编辑**内部跟进备注**（`follow_note`） | — | 客户分级标签 A/B/C |
| **工单** | 列表与状态流转；**已派单**时可填「指派说明」（`assignee` 文本，如师傅姓名） | 状态变更触发订阅消息（见下表） | 多师傅路由、派单系统 |
| **订阅消息** | **不强制**：预约/工单以 Toast + 站内「我的」列表与详情刷新为准 | 接入「新预约→供应商」「工单更新→客户」模板并验收 | 优惠类、配送当日类等 |
| **优惠活动** | **不做**：无发券、无「我的优惠券」业务逻辑；首页 Banner 可链到静态文案或隐藏活动入口 | — | 活动页、优惠券、优惠类订阅消息 |
| **小程序码** | **默认不做** | 可选加菜：带 `source` 写库 | 全渠道统计看板 |
| **合作方案 `plans`** | 前台读库表/种子数据；**一期无**「后台方案编辑」页，内容由发版或 SQL 初始化维护 | — | 运营后台可视化改方案 |


## 六、技术架构

### 6.1 技术选型

| 层级 | 选择 | 说明 |
|------|------|------|
| 开发框架 | **UniApp**（推荐） | 一套代码同时发布小程序 + H5，基于 Vue3 |
| UI 组件库 | **uni-ui** / Vant Weapp | 成熟移动端组件，开箱即用 |
| 状态管理 | Pinia | 管理用户信息、产品缓存等全局状态 |
| 数据库 | **Supabase**（PostgreSQL） | 免费 500MB，REST API 直接调用 |
| 图片存储 | **Supabase Storage** | 免费 1GB，CDN 加速，直传直取 |
| 后端 API | Supabase REST API + Edge Functions | 无需自建服务器 |
| 地图 | 腾讯地图（`<map>` 组件） | 小程序原生支持 |
| 微信能力 | 微信原生 API | wx.login / wx.getLocation / 订阅消息等 |

### 6.2 UniApp 的核心优势

```
UniApp 优势：
├── 一套代码 → 同时发布微信小程序 + H5网页 + App
├── 基于 Vue3，学习成本低
├── uni-ui 组件库完善
├── HBuilderX IDE 支持，真机调试方便
└── 后期若想上 App，直接打包，无需重写
```

### 6.3 数据流设计

```
小程序前端（C端）
├── GET  products        → Supabase（读取上架产品）
├── POST customers       → Supabase（提交预约信息）
├── POST repair_orders   → Supabase（提交报修工单）
├── 图片上传             → Supabase Storage（直传，返回 URL）
└── 微信 openid          → Supabase users 表（身份绑定）

供应商后台（B端）
├── CRUD products          → Supabase（产品增删改查）
├── PATCH is_active        → Supabase（上架/下架）
├── GET/PATCH customers    → Supabase（客户列表、详情；更新 status、follow_note）
├── GET/PATCH repair_orders → Supabase（工单列表、状态、handler_notes、assignee）
└── 聚合查询               → 后台首页「今日新增客户数」「待处理工单数」（可由前端按日期/status 聚合或轻量视图）
```

### 6.4 鉴权方案

```
普通客户：
wx.login() → code → 换取 openid → 生成 JWT Token → 存本地
每次请求携带 Token → Supabase RLS 策略校验权限

管理员：
特定 openid 绑定 admin 角色（Supabase users 表 role 字段）
访问 /admin/* 页面时校验 role === 'admin'，否则跳回首页
```

## 七、数据库设计（Supabase）

```sql
-- 用户表（微信登录）
CREATE TABLE users (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  openid     TEXT UNIQUE NOT NULL,
  nickname   TEXT,
  avatar_url TEXT,
  role       TEXT DEFAULT 'customer',   -- 'customer' | 'admin'
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 产品分类表
CREATE TABLE categories (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name       TEXT NOT NULL,
  slug       TEXT UNIQUE NOT NULL,      -- 'beer' | 'beer_machine' | 'beer_car'
  sort_order INT DEFAULT 0
);

-- 产品表
CREATE TABLE products (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name          TEXT NOT NULL,
  category      TEXT NOT NULL,           -- 'beer' | 'beer_machine' | 'beer_car'
  description   TEXT,
  spec          TEXT,
  price_range   TEXT,
  supply_type   TEXT DEFAULT 'both',     -- 'sell'（出售）| 'rent'（租赁）| 'both'（均可）
  cover_image   TEXT,                    -- Supabase Storage URL
  images        JSONB DEFAULT '[]',      -- 详情图 URL 数组
  is_active     BOOLEAN DEFAULT true,
  sort_order    INT DEFAULT 0,
  tags          JSONB DEFAULT '[]',
  created_at    TIMESTAMPTZ DEFAULT NOW(),
  updated_at    TIMESTAMPTZ DEFAULT NOW()
);

-- 客户意向表
CREATE TABLE customers (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES users(id),
  name            TEXT NOT NULL,
  phone           TEXT NOT NULL,
  address         TEXT,
  location        JSONB,               -- {latitude, longitude}
  biz_type        TEXT,                -- 'night_stall'|'open_restaurant'|'market'|'other'
  daily_volume    TEXT,                -- '<50'|'50-100'|'>100'
  interested_plan TEXT,                -- 'basic'|'standard'|'premium'|'undecided'
  need_beer_car   BOOLEAN DEFAULT false, -- 是否需要啤酒车（独立选配）
  beer_car_type   TEXT,                -- 'buy'（购买）|'rent'（租赁）
  delivery_area   TEXT,                -- 配送区域（珠三角/其他省市）
  status          TEXT DEFAULT 'pending', -- 'pending'|'contacted'|'signed'|'lost'
  source          TEXT,                -- 来源渠道（扫码/搜索/分享）
  notes           TEXT,                -- 客户预约表单填写的备注
  follow_note     TEXT,                -- B 端内部跟进备注（C 端不可见）
  created_at      TIMESTAMPTZ DEFAULT NOW(),
  updated_at     TIMESTAMPTZ DEFAULT NOW()
);

-- 报修工单表
CREATE TABLE repair_orders (
  id             UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id        UUID REFERENCES users(id),
  customer_name  TEXT NOT NULL,
  phone          TEXT NOT NULL,
  device_type    TEXT NOT NULL,        -- 'beer_machine'|'beer_car'|'other'
  issue_desc     TEXT NOT NULL,
  issue_images   JSONB DEFAULT '[]',   -- 故障照片 URL
  preferred_time TIMESTAMPTZ,
  status         TEXT DEFAULT 'pending', -- 'pending'|'assigned'|'processing'|'done'
  assignee       TEXT,                 -- 已派单时可选填：指派对象说明（文本）
  handler_notes  TEXT,
  created_at     TIMESTAMPTZ DEFAULT NOW(),
  updated_at     TIMESTAMPTZ DEFAULT NOW()
);

-- 合作方案表（动态配置，支持后台编辑）
CREATE TABLE plans (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name        TEXT NOT NULL,
  level       TEXT NOT NULL,           -- 'basic'|'standard'|'premium'
  description TEXT,
  features    JSONB DEFAULT '[]',      -- 包含项列表
  excluded    JSONB DEFAULT '[]',      -- 不含项列表
  is_active   BOOLEAN DEFAULT true,
  sort_order  INT DEFAULT 0
);
```
