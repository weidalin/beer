## 四、QA 代码审查 Bug 报告

### BUG-001 ⭐ P1 — FloatContact 缺少"查看微信二维码"选项

**发现时间：** 2026-05-12  
**优先级：** P1  
**所属模块：** C端 / 公共组件  

**问题描述：** 悬浮联系按钮弹出的 ActionSheet 仅有两个选项（拨打电话、复制微信号），缺少产品规格要求的"查看微信二维码"第三个选项。v2 将同步扩展为四项（含"在线咨询"）。

**复现步骤：**
1. 进入任意 C 端页面
2. 点击右下角"联系我们"悬浮按钮
3. 查看 ActionSheet 选项数量

**预期结果：** ActionSheet 显示三个选项：[拨打电话] [复制微信号] [查看微信二维码]  
**实际结果：** ActionSheet 仅显示两个选项：[拨打电话] [复制微信号]  
**关联规格：** 产品计划书 §3.1、TC-007

---

### BUG-002 ⭐ P2 — 预约/报修表单校验错误提示为 Toast，非字段内联红字

**发现时间：** 2026-05-12  
**优先级：** P2  
**所属模块：** C端 / 预约表单 / 报修表单  

**问题描述：** 两个表单的校验失败提示使用 `uni.showToast`（顶部通知条），而测试用例 TC-005 期望在对应字段下方展示红色内联文案（"请填写姓名"），提示更清晰。功能可用，但体验偏差。

**复现步骤：**
1. 进入预约页，不填写姓名
2. 点击"提交预约申请"
3. 观察错误提示样式

**预期结果：** 姓名字段下方出现红色文字"请填写姓名"  
**实际结果：** 屏幕顶部弹出 Toast"请填写姓名"，1.5 秒后消失  
**关联规格：** TC-005、TC-006

---

### BUG-003 ⭐ P1 — 腾讯地图 Key 未配置，配送区域地图可能无法正常渲染

**发现时间：** 2026-05-12  
**优先级：** P1  
**所属模块：** C端 / 配送区域地图  

**问题描述：** `.env` 中 `VITE_TMAP_KEY` 的值为占位文字"你的腾讯地图Key"，未配置真实 Key。小程序 `<map>` 组件在真机上需要有效的腾讯地图 API Key，否则地图底图无法加载。

**复现步骤：**
1. 在真机/开发者工具打开小程序
2. 进入"我的" → "查看配送区域"
3. 观察地图是否正常显示

**预期结果：** 显示珠三角区域地图底图  
**实际结果：** 地图底图可能空白或报 Key 无效错误  
**修复建议：** 前往[腾讯位置服务控制台](https://lbs.qq.com)申请小程序 Key，填写到 `.env` 后重新编译

### BUG-004 ⭐ P0（安全） — .env 包含七牛云密钥明文

**发现时间：** 2026-05-12  
**优先级：** P0（安全）  
**所属模块：** 基础设施  

**问题描述：** `.env` 文件中包含七牛云 Access Key 和 Secret Key 的明文。v2 将正式接入七牛云用于图片存储，但密钥必须从前端彻底移除，改由服务端（Edge Function）管理。

**修复建议：**
1. 立即从 `.env` 中删除七牛云 ak/sk
2. 如该密钥已有历史提交记录，需在七牛云控制台轮换密钥
3. 将 `.env` 加入 `.gitignore`，确保不提交到仓库
4. v2 图片上传通过签名接口获取 UpToken，AK/SK 仅存服务端

---

### BUG-005 ⭐ P2 — 预约成功后弹出 showModal 而非 Toast，体验与规格不一致

**发现时间：** 2026-05-12  
**优先级：** P2  
**所属模块：** C端 / 预约表单  

**问题描述：** 预约提交成功后，代码弹出 `uni.showModal`（模态确认弹窗），需用户手动点击"确定"才能返回；产品规格（TC-005）期望弹出 2 秒 Toast 后自动跳转。

**实际结果：** 弹出标题为"提交成功！"的 Modal 弹窗，用户需手动点击"确定"  
**预期结果：** Toast"提交成功"，2 秒后自动跳转"我的预约"列表  
**关联规格：** TC-005
