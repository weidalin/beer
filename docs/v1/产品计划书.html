一项目背景与目标

1.1 业务背景

本项目为精酿啤酒一站式供应链打造专属微信小程序，核心客户群体为宵夜档、大排档及小型餐饮档口老板。

业务类型说明
桶装鲜啤配送按需定期送货上门（珠三角当日达，其他地区走物流）
设备提供打酒机、啤酒车；支持出售或租赁两种方式，客户按需选择

1.2 为什么选择微信小程序

对比维度网页版微信小程序
触达方式需用户主动搜索/记住网址扫码、搜索、好友分享即可打开
用户门槛需注册账号才能使用无需注册/登录即可浏览全部内容
分享获客分享链接体验差分享卡片，好友点击直接进入
消息触达无法主动推送订阅消息（新意向提醒等）
目标用户适配需记住网址，门槛略高档口老板日常用微信，完全匹配
在线支付需额外接入本期不接入；价格面议，线下结算
核心结论：目标客户（宵夜档/大排档老板）的主要数字工具就是微信，小程序比网页更贴近使用场景，获客成本更低，转化率更高。

3.4 合作意向登记

体验优先：无需登录即可提交。仅昵称与联系电话为必填，其余字段全部选填，最大程度降低填写门槛。
字段必填说明
您的昵称必填联系人称呼
联系电话必填供应商回电联系，前端校验格式
档口地址选填支持 wx.getLocation() 定位自动填写，拒绝授权不影响提交
营业类型选填宵夜档 / 大排档 / 夜市摊 / 其他
月均啤酒销量选填50桶以下 / 50-100桶 / 100桶以上
感兴趣的方案选填基础版 / 标准版 / 旗舰版 / 还没想好
是否需要啤酒车选填不需要 / 需要购买 / 需要租赁
配送区域选填珠三角（当日达）/ 其他省市（走物流）
备注选填自由填写

提交逻辑

  • 仅校验昵称与手机号，其余字段为空时正常写入（留空）
  • 数据写入云开发数据库 customers 集合
  • 已登录时附带 openid 关联记录，登录后可在「我的」查看
  • 未登录时匿名写入（无 openid，「我的」不显示该条）
  • 提交成功 → Toast「已提交，我们会尽快联系您」

5.2 图片上传（微信云存储）

// 1. 选择图片
wx.chooseMedia({
  count: 1,
  mediaType: ['image'],
  success(res) {
    const tempFilePath = res.tempFiles[0].tempFilePath

    // 2. 上传至微信云存储
    wx.cloud.uploadFile({
      cloudPath: `products/${Date.now()}-${Math.random()}.jpg`,
      filePath: tempFilePath,
      success(uploadRes) {
        const fileID = uploadRes.fileID  // 存入数据库
      }
    })
  }
})

// 3. 前台展示时获取临时访问 URL
wx.cloud.getTempFileURL({
  fileList: [fileID],
  success(res) {
    const url = res.fileList[0].tempFileURL
  }
})
