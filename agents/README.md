## 协作关系图

```
        ┌──────────────────────────────┐
        │         产品经理（PM）         │
        │  需求 + 项目协调 + 用户视角    │
        └──────────┬───────────────────┘
                   │
        ┌──────────┴──────────┐
        ↓                     ↓
┌──────────────┐     ┌──────────────┐
│  开发（DEV） │────→│  测试（QA）  │
│  实现需求     │←────│  反馈 Bug    │
└──────────────┘     └──────────────┘

信息流：
PM 定义需求 → DEV 实现 → QA 测试 → PM 验收（AC + 用户场景）
QA 发现 Bug → DEV 修复 → QA 回归 → PM 确认
```

## Sprint 节奏

| 时间 | 活动 | 参与角色 |
|------|------|---------|
| 周一 | Sprint 启动，确认本周任务 | PM + DEV + QA |
| 每日 | 异步状态同步（文字更新） | DEV + QA |
| 周五 | Sprint 结束：DEV 演示 → PM 验收 → QA 确认 | PM + DEV + QA |

**每日同步格式：**
```
[DEV / QA] 今日更新
- 昨日完成：xxx
- 今日计划：xxx
- 阻塞/风险：xxx（无则填"无"）
```
