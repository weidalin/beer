## 协作关系图

```
        ┌──────────────────────────────┐
        │         产品经理（PM）         │
        │  需求 + 项目协调 + 用户视角    │
        └──────────┬───────────────────┘
                   │
        ┌──────────┴──────────┐
        ↓                     ↓
┌──────────────┐     ┌──────────────┐
│  开发（DEV） │────→│  测试（QA）  │
│  实现需求     │←────│  反馈 Bug    │
└──────────────┘     └──────────────┘

信息流：
PM 定义需求 → DEV 实现 → QA 测试 → PM 验收（AC + 用户场景）
QA 发现 Bug → DEV 修复 → QA 回归 → PM 确认
```

## Sprint 节奏

| 时间 | 活动 | 参与角色 |
|------|------|---------|
| 周一 | Sprint 启动，确认本周任务 | PM + DEV + QA |
| 每日 | 异步状态同步（文字更新） | DEV + QA |
| 周五 | Sprint 结束：DEV 演示 → PM 验收 → QA 确认 | PM + DEV + QA |

**每日同步格式：**
```
[DEV / QA] 今日更新
- 昨日完成：xxx
- 今日计划：xxx
- 阻塞/风险：xxx（无则填"无"）
```

## 项目功能点

### C端（客户侧）

| 模块 | 核心功能 |
|------|---------|
| **首页** | Banner 轮播、三大核心优势、快捷入口（了解方案 / 提交合作意向 / 联系我们）、热门产品横滑、合作数据展示、客户口碑、悬浮联系按钮 |
| **产品展示** | 分类筛选（桶装鲜啤 / 打酒机 / 啤酒车）、搜索、双列卡片；详情页多图轮播、规格 / 供货方式展示、一键咨询 |
| **合作方案** | 基础版 / 标准版 / 旗舰版对比切换；啤酒车独立选配说明（不与任何方案捆绑）；方案对比横向滑动表 |
| **合作意向登记** | 填写姓名、电话、档口地址（支持定位自动填写）、营业类型、月均销量、感兴趣方案、啤酒车需求、配送区域、备注；提交后可在"我的记录"查看 |
| **在线咨询** | 微信客服组件（open-type="contact"）；ActionSheet 聚合：微信在线咨询 / 拨打电话 / 复制微信号；入口覆盖首页悬浮按钮、产品详情「一键咨询」、合作方案页、「我的」联系我们 |
| **我的** | 微信一键授权登录（主动触发，无需强制）、我的合作意向记录、联系我们（电话 / 微信客服）、关于我们 / 常见问题 |

### B端（供应商后台）

| 模块 | 核心功能 |
|------|---------|
| **产品管理** | 新增 / 编辑产品；上传主图 + 详情图（微信云存储）；设置分类 / 规格 / 供货方式；一键上架 / 下架；排序权重 |
